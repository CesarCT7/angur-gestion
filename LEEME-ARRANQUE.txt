ANGUR GESTIÓN | VERSIÓN LOCAL PARA ADMINISTRADORES

1. En Windows, elige «Extraer todo» y abre la carpeta del proyecto.
2. Necesitas un JDK 21 y una base MySQL. Si usas la base administrativa de
   esta misma computadora, copia en privado el .env de la carpeta original
   angur-gestion-solo-administrador a la carpeta extraída, junto a pom.xml.
   Si vienes del ZIP del 21 de noviembre y usas otra instalación, respalda
   su base administrativa y ejecuta una vez en MySQL la migración
   src/main/resources/db/migrations/007-cotizaciones-sin-cliente.sql.
3. Para usar la aplicación compilada, abre una terminal en esa carpeta y ejecuta

   .\iniciar-angur.cmd --jar

   El navegador abrirá el login en el puerto de tu configuración. Deja la
   ventana abierta mientras uses la aplicación. Para recompilar desde las
   fuentes, abre iniciar-angur.cmd sin argumentos.

Instalación nueva
El paquete trae .env.example. El arrancador genera el .env si falta. Con
Docker y los puertos libres puede preparar MySQL y Mailpit. Si usas MySQL
propio, ajusta DB_URL, DB_USER y DB_PASSWORD, selecciona ANGUR_USE_DOCKER=false
y prepara la base con src/main/resources/db/schema.sql. El README explica
cómo aplicar migraciones en una instalación existente. El ZIP incluye el
esquema. Los usuarios, ventas y demás registros permanecen en tu base.

En una base nueva, abre /setup para crear el primer administrador. En una
base existente, entra con tu cuenta de administrador. El correo externo de
recuperación o aprobación requiere SMTP. Mailpit permite ver correos locales.

Si falla el arranque, revisa .tmp/arranque.log en la carpeta extraída.
